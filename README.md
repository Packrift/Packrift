# Packrift

Packrift builds agent-accessible packaging and shipping-supplies tools for business buyers.

- Storefront: https://packrift.com
- Agent guide: https://packrift.com/pages/agents
- Public MCP endpoint: https://mcp.packrift.com/mcp
- MCP server card: https://packrift.com/.well-known/mcp/server-card.json
- llms.txt: https://packrift.com/llms.txt

## Open Technical Assets

### Packrift MCP

`packrift-mcp` is the public Model Context Protocol server for the Packrift catalog. It lets agents search packaging products, retrieve live pricing and inventory, recommend packaging by dimensions and use case, estimate shipping, and build cart URLs.

Repository: https://github.com/Packrift/packrift-mcp
